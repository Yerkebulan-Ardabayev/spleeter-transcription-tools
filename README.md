# Python Media Tools

Коллекция инструментов для работы с медиа файлами на Python.

## 📁 Проекты

### 🎵 voice-cleaner
Очистка голоса в видео через Demucs AI — извлекает вокал и отделяет его от фоновой музыки/шума.

**Использование:**
```bash
cd voice-cleaner
start.bat
```

**Требования:**
- Python 3.10
- demucs, pydub, imageio-ffmpeg

---

### ✂️ video-splitter
Разделение видео на части по времени (ffmpeg segment, без перекодировки).

**Использование:**
```bash
cd video-splitter
start.bat
```

**Функционал:**
- Нарезка видео на равные части заданной длительности (по умолчанию 40 мин)
- `-c copy` — мгновенная нарезка без потери качества

---

### 🎤 audio-transcriber
Автоматическая транскрипция аудио в текст через faster-whisper (large-v3).

**Использование:**
```bash
cd audio-transcriber
start.bat
```

**Функционал:**
- Распознавание речи из аудио файлов
- Сохранение прогресса обработки
- Поддержка различных форматов аудио

---

## 🚀 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Yerkebulan-Ardabayev/programs.git
cd programs
```

2. Установите зависимости для каждого проекта

## 📝 Примечания

- Все рабочие файлы (медиа, временные файлы) исключены из репозитория
- Каждый проект имеет свой `start.bat` для быстрого запуска
